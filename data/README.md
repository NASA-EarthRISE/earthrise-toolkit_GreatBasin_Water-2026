# data/

Inputs that are **not** committed, either because they are too large for git or
because they are produced by a calibration run rather than authored here.

Nothing in this directory is tracked except this file — see `.gitignore`.

## Expected layout

```
data/
├── README.md                       # this file (tracked)
├── threshold_cv_summary.csv        # calibrated thresholds
└── nwi/
    ├── GSL_Wetland_Raster.tif      # ~114 MB
    └── Abert_Wetlands_Raster.tif   # ~8 MB
```

Every path is overridable, so you can keep these anywhere:

| Variable | Default | Used by |
|----------|---------|---------|
| `THRESHOLD_CSV` | `data/threshold_cv_summary.csv` | `water_extent_timeseries.py` |
| `NWI_DIR` | `data/nwi/` | `final_threshold_optimization.py` |

## `threshold_cv_summary.csv`

Needs `site`, `index`, `reference`, `threshold_mean`, and `cv_iou` columns. The
highest-`cv_iou` NDWI row and NDVI row are selected per site.

It is **not** generated by anything in this repository — it came from the
superseded `threshold_optimization_cv.py`. The current calibration script,
`final_threshold_optimization.py`, writes
`outputs/tables/final_threshold_summary.csv`, which has the same required
columns and can be used directly:

```bash
export THRESHOLD_CSV=outputs/tables/final_threshold_summary.csv
```

Be aware this is a *different, later* calibration, so the water extents it
produces will not match a run against the legacy table.

## NWI wetland rasters

One raster per site, where pixel value 1 marks wetland. Derived from the USFWS
[National Wetlands Inventory](https://www.fws.gov/program/national-wetlands-inventory)
and rasterised to the study AOIs.

They are excluded from git deliberately: `GSL_Wetland_Raster.tif` is ~114 MB,
above GitHub's 100 MB per-file hard limit, and binary rasters committed to
history stay there permanently. Share them through the team's OneDrive, or
re-derive them from the NWI source.

Only the NDMI/wetland calibration reads them. Without them,
`final_threshold_optimization.py` still completes its NDWI and NDVI work and
reports the NDMI step as skipped.
